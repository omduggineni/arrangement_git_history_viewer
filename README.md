# Arrangement Diff Viewer

Git history and diff viewer for MuseScore arrangements, in two versions:

- [`cross_platform/`](cross_platform/README.md): Python + pywebview app for macOS, Windows and Linux.
- [`swiftui/`](swiftui/README.md): native SwiftUI app for macOS.

Run `make help` at the top level for build targets. CI (`.github/workflows/build.yml`) builds the
cross_platform app for macOS/Windows/Linux and the SwiftUI app for macOS.
